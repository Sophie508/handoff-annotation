# Node-Decision Annotation Interface

Pilot annotation interface for the handoff-bench human-factor study: a
preference-parameter quiz (λ, β, ρ, α, B) followed by independent
CONTINUE / STOP / ESCALATE labeling of trajectory-tree decision points,
with optional voice rationales. Fully static — answers and recordings stay
in the annotator's browser and leave only as a downloadable zip.

Live: https://sophie508.github.io/handoff-annotation/
